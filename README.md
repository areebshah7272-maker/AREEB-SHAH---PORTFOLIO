# AREEB SHAH — Digital Portfolio

A premium, responsive portfolio for Areeb Shah, built with semantic HTML, modern CSS and lightweight vanilla JavaScript.

## Experience

- Pearl, Deep Ink and Electric Blue visual system
- Purpose-built mobile, tablet and desktop compositions
- SADAT STORE flagship commerce case study
- Hero entrance, scroll reveal, staggered cards and marquee motion
- Magnetic calls-to-action, pointer depth and subtle parallax
- Keyboard-friendly mobile navigation and visible focus states
- Reduced-motion support and a no-JavaScript content fallback
- No frameworks, build step, third-party scripts or remote font requests

## Preview locally

Serve this folder with any static file server and open `index.html` through that server. For example:

```bash
python -m http.server 4173
```

Then visit `http://localhost:4173`.

## Project structure

- `index.html` — semantic page structure and portfolio content
- `styles.css` — visual system, responsive layouts and motion
- `script.js` — progressive enhancement for reveal, depth, navigation and active states
- `_headers` and `_redirects` — Cloudflare Pages defaults
